1. API:  API 是程序和程序之间沟通的通道，提前约定通信规则，让程序不用暴露内部细节，就能互相传递数据。

## 区分两个容易混淆的概念

1）普通函数（例如 Python 内置函数）
属于**同一个程序内部**的调用，可以理解为「程序内 API」
2）课程里讲的 Web API（Spotify 这种）
**两台不同电脑上的程序，通过网络互相调用**，这是后端开发、FastAPI、你项目要用的 API。

2. # FastAPI

**FastAPI 是一个 Python 工具包（Web 框架），用来快速写出 Web API。**

## 拆分理解

 1. Spotify API：别人已经写好、部署在网上的接口，**你负责调用它**
你的代码 → 网络 → 请求 Spotify API → 获取歌曲数据
 2. FastAPI：帮你**自己造 API**
你写代码用 FastAPI 搭建服务，对外开放接口；
其他人 / 其他程序（前端、Python 脚本）通过网络来调用你写的 API。

# 2. 举个对照例子
✅ Spotify 团队：他们当初很可能用某一种框架（不一定是 FastAPI）开发出 Spotify API。
✅ 现在的你：使用 FastAPI，创造属于你自己的 API 服务。

3. ##  最简单定义

**路由 = URL 地址 + 对应的处理代码**
作用：服务器收到网络请求时，根据访问的地址，找到该执行哪一段代码。
